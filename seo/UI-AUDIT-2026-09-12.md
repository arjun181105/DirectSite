# DirectSite UI and conversion audit — 12 September 2026

## Scope and evidence

Viewed the actual live homepage and plumbing landing page as screenshots, then inspected the redesigned landing page and industry directory in the browser. Reviewed simulated-mobile Lighthouse screenshots of the homepage and plumbing page. Checked the shared demo navigation and form without a phone number.

## Changes

- Stronger commercial-page hierarchy: a focused hero, visible three-step demo process, primary demo request and separate direct calendar link.
- Shared navigation opens the demo form directly rather than adding a detour through the contact page.
- Industry/resource hubs use descriptive cards instead of a long set of bare links.
- Section navigation and a desktop sidebar help readers scan longer content; mobile layouts stack naturally.
- Typography, spacing, buttons, comparison-table rows and resource cards now share the existing warm brand palette. No stock imagery is presented as client work.
- Home page CTA text describes the demo request it opens. Removed unsupported 10-minute wording.
- Phone is optional in the demo form; email stays required. Browser verification reached the next step with the phone blank.
- Existing titles, canonicals, schema graphs, FAQs, internal URLs and crawler controls retained and validated.
